# Logos

The Kuk Sool Won emblem (fist, staffs, ribbons, 국술원 and "KUK SOOL WON" lettering), single ink in the logo yellow `#ffdd00`.

- On dark grounds (header in dark mode, footer, black bands) use it as is, in yellow.
- On light grounds the site turns it black with `filter: brightness(0)`; the yellow version on hall-white has too little contrast.
- Never recolour it to jade or place it on a yellow field.
