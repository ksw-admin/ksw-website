# Medals

Results as coloured dots with counts: gold, silver, bronze, then "+n" for further placings.

- Only colours with a count above zero are shown; a post without results shows nothing.
- `gold`, `silber`, `bronze` are data colours; never use them for decoration.
- The group carries a spoken label ("5 Gold, 4 Silber, 2 Bronze").
- The site adds them up per season ("2026: 37 Platzierungen").
- Hand-written from `src/components/Medals.astro`.
