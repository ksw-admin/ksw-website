# PhoneLink

The phone number as the largest call to action in the contact band: a yellow round handset icon, then the number in condensed type.

- Yellow on the black `panel` band; the icon is a yellow circle with a black handset and tilts slightly on hover.
- A `tel:` link with "Anrufen:" for screen readers before the number.
- This is the system's only icon; it exists to show the number can be tapped.
- Hand-written from `src/components/Visit.astro`.
