# CredentialList

Peter's qualifications as a short two-column list: area in `stein`, qualification in `fg`, in the old site's wording.

- Keep it to about four rows with short labels ("Verbände", not "Verbandszugehörigkeiten"): a longer list and a wider label column made the section feel heavy. If an area repeats anyway, it is shown once with both values under it.
- Plain text only: no badges, belt graphics or icons (a five-stripe belt was tried and removed as gimmicky).
- On phones the two columns stack.
- Hand-written from `src/components/Master.astro`; data from `site.json` › `master.credentials`.
