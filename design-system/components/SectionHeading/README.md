# SectionHeading

A condensed heading standing on the 2px section rule in the text colour, with an optional text link on the right.

- Opens every content section (news, gallery, legal pages). The rule is the system's main structural device; do not add other dividers above it.
- The heading is condensed (`font-stretch: 62%`), weight 900, sentence case.
- The link names its target ("Alle Beiträge"), no arrow.
- Hand-written from `src/styles/global.css` (`.sec-h`); a static rendition.
